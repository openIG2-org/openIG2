# 2026-10-22: the tutorial interpreter (`TutorialFrissit`, `TutorialGetNextCommand`) against the exe

`tools/trace/run_tutorial.py <install> <out> --chapters N --seconds 560 --start-after 300` (Frida 17, GOG `ig2.exe`,
which ran the Hungarian `main.tut`, 55,300 bytes; the replay picks the language by the traced length). The tracer
starts chapter N as the main menu's choice does and records each `TutorialFrissit` (exe 0x60c020) tick: the inputs
(`AktKep`, `Counter`, `Atlepes|Belep`, `SelfPlaying`, the `.mou` index and counters before, the planet and vehicle
counts the events read, the screen gates at entry) and the interpreter's state after it (`re/rules/tutorial.md` §1,
the text window's grid and queue when changed); each `TutorialGetNextCommand` (0x60c570) with its argument, return
value and hooked calls; each `TutorialCheckEvent` (0x60bdf0) between ticks. Events the script waits for are fired
by the tracer after 300 UI ticks (the player's action), `WAITFORBATTLE` cleared after 600. Chapters ran two at a
time in separate game instances.

`engine/crates/ig2-sim/tests/tutorial_trace.rs::tutorial_matches_the_exe` starts the port the same way and compares
every tick bit for bit (f32 window position, steps and typing counter included), the queue and grid when recorded,
the `GIVE MONEY` amounts and the use of every hooked call result.

Found on the way: the exe's `GetInt` (0x60bcc0) takes `0-9 . -` runs (the ELF's `IsNumber` symbol was a wrong
match); the screen gates `KepernyokLetiltva` are written between ticks by other code (index 13 set at a chapter's
start before its first tick); the planet and vehicle baselines of `TutorialInitEvents` are taken at the
`WAITFOREVENT` tick (the first traces had the counts only on paused ticks; the replay takes the next recorded value).
Not covered at runtime: TIME, COUNT, LOADSAVEGAME, IRRITATEME, GOTO SCREEN, SEND MESSAGE, RESTART, TEXTURE, QUIT, END
(unused by the shipped script) and `Game::tutorial_effect`'s writes, which have a save-based test
(`tests/save_replay.rs::tutorial_effects_write_the_game`) only.
