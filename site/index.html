openIG2

The 1999 space strategy classic Imperium Galactica II, on a new open-source engine: the original game, built for multiplayer, modern displays and today's hardware.

Download for Windowslatest release Source on GitHub

Free and open source (AGPL-3.0). You need your own copy of the game from GOG.

What you get

The whole game

Campaigns, scenarios, skirmish, the tutorial and multiplayer, with every screen of the original: starmap, colonies, ground war, space battles, research, design, trade, diplomacy and espionage.

Rules, bit for bit

The simulation matches recordings of the original game tick for tick. Your original save games load and play on.

Multiplayer first

LAN discovery, direct IP, private rooms with join codes, optional port mapping, rejoin after a drop, host migration and multiplayer saves.

Modern displays

Any resolution and refresh rate, smoothly interpolated. High DPI, 4K and ultrawide; window, borderless or fullscreen.

Classic by default

It looks, sounds and handles like the original. Every deliberate change is an opt-in enhanced option.

No assets included

The engine reads graphics, text, voices and rules from your own install, so nothing of the original is copied.

How to play

  1. Own the game. Install Imperium Galactica II from GOG.
  2. Download openIG2. Get the latest zip from the releases page.
  3. Unzip and play. Put it into the game's folder and run ig2-client.exe. It also finds the game on its own if you unzip it elsewhere.
