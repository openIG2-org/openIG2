# Names and forks

*Imperium Galactica* and *Imperium Galactica II* are the names of their rights holders' games; openIG2 uses them
only to say which game it plays. openIG2 is not affiliated with or endorsed by them.

"openIG2" names this project. The code is free under the AGPL-3.0, and forks are welcome; if you publish a fork,
please give it a name of its own, say that it is based on openIG2 with a link to this repository, and don't
present your builds as official openIG2 releases.
